# 筋トレメモ

筋トレ・有酸素を記録するPWA。将来は友達との記録共有（筋トレ版Strava）を追加予定。機能一覧は [docs/features.md](docs/features.md)。

## 現在できること（Phase 1）
- 重量トレ(重量×回数)・自重・有酸素(時間/距離/ペース自動計算)の記録
- 種目プリセット＋オリジナル種目、前回記録の表示、セットのコピー
- 履歴、自己ベスト(PR)の自動検出、種目別の成長グラフ、週間サマリー
- JSON/CSVエクスポート、JSONインポート、全データ削除
- オフライン動作（データは端末のIndexedDBに保存。アカウント不要）

## 開発
```
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト
npm run build    # 本番ビルド(dist/)
```
`dist/` は Cloudflare Pages / GitHub Pages / Vercel などの無料静的ホスティングにそのまま置けます。

## 注意
- 記録は端末ごとに保存されます。機種変更前に設定画面からバックアップしてください。
- 色などのトークンはデジタル庁デザインシステムを参考にした値です。公式の最新トークンに合わせて調整してください（`src/styles.css`）。
