# Gym Bro

筋トレ・有酸素を記録するPWA。将来は友達との記録共有（筋トレ版Strava）を追加予定。機能一覧は [docs/features.md](docs/features.md)。

## 現在できること（Phase 1: 記録 / Phase 2: 友達共有）
- 重量トレ(重量×回数)・自重の記録。新しい種目は最初から3セット分の入力欄が出る(有酸素は一旦削除)
- 種目プリセット＋オリジナル種目、前回記録の表示、セットのコピー
- カレンダーで記録のある日を選ぶと「Continue this workout」でその日のワークアウトを開いて続きから記録できる
- 記録画面は自動保存(Saveボタン不要)。何か入力すると端末に保存され、友達への共有も自動で行われる。まだ何も入力していない新規画面の内容だけは下書きとして残る
- 自作種目の名前変更・削除(Settings)、記録済みの種目の入れ替え(各種目の「Change」)
- 推定1RMの自己ベストを更新したらお祝い画面(トロフィーと紙吹雪)を表示。記録の画像(PNG)を保存・共有できる
- 重量×回数を入れると推定1RMを表示。履歴、自己ベスト(PR)の自動検出、週間サマリー
- 成長グラフ: 記録した日を下に表示、点をタップで数値、点が多いと横スワイプ
- JSON/CSVエクスポート、JSONインポート、全データ削除
- オフライン動作（データは端末のIndexedDBに保存。アカウント不要）
- **友達共有（Phase 2）**: アカウント作成、招待コードで友達追加、保存した記録の自動共有、フィード、友達ごとの記録カレンダー、Teams風の絵文字リアクション(1人が1つのワークアウトに1つ。別の絵文字を押すと差し替え)、コメント(フィードは20件ずつ「Load more」)、プロフィールページ(写真・名前・自己紹介)、友達の記録のカレンダーとProgress閲覧、友達の新規記録をFriendsタブの青い点で通知(アプリを開いている間。端末が閉じている間のプッシュ通知は未対応)。設定手順は [docs/SETUP.md](docs/SETUP.md)。サーバー設定なしでビルドすると共有機能は無効になり、従来どおり端末内だけで動きます

## 開発
```
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト
npm run build    # 本番ビルド(dist/)
```
`dist/` は Cloudflare Pages / GitHub Pages / Vercel などの無料静的ホスティングにそのまま置けます。

## 注意
- 内部のデータ保存名とバックアップ形式の識別子は旧名 `kintore-memo` のままです(変えると既存の記録や古いバックアップが読めなくなるため)。
- 記録は端末ごとに保存されます。機種変更前に設定画面からバックアップしてください。
- UIは英語・Notion風（文字色＋青のアクセント1色）。色は `src/styles.css` の変数で変更できます。
